# OpenGW — PlayStation 1 port

A port of [OpenGW] (Peter Hirschberg, GPL-3.0) from SDL3 + OpenGL to
the PlayStation, using the **PSYQo** SDK.

Build: `make` → `opengw.ps-exe`
